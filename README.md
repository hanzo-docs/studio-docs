# Hanzo Studio Documentation

Official documentation for Hanzo Studio - guides, tutorials, API reference, and architecture documentation.

## Documentation Site

Visit [docs.studio.hanzo.ai](https://docs.studio.hanzo.ai) for the full documentation.

## Contents

- **Getting Started** - Installation, quickstart guides
- **Tutorials** - Step-by-step guides for common workflows
- **API Reference** - Complete API documentation
- **Architecture** - System design and implementation details
- **Contributing** - How to contribute to Hanzo Studio
- **Custom Nodes** - Creating and publishing custom nodes

## Building Locally

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```
